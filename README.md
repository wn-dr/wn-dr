## 📊 Projeto em destaque

### Análise Exploratória de Vendas de um E-commerce

Projeto desenvolvido no **Google Colab**, utilizando Python e suas principais bibliotecas de análise e visualização de dados.

O objetivo do projeto foi preparar, analisar e interpretar uma base de vendas, buscando identificar padrões e produzir recomendações de negócio.

### Etapas desenvolvidas

- Carregamento e validação da base;
- Análise das dimensões e dos tipos de dados;
- Identificação de valores ausentes;
- Remoção de registros duplicados;
- Investigação de possíveis outliers;
- Criação de novos atributos;
- Agrupamento dos dados por região e dia da semana;
- Criação de gráficos;
- Interpretação dos resultados;
- Desenvolvimento de recomendações.

### Principais resultados

| Indicador | Resultado |
|---|---:|
| Total de vendas analisado | R$ 3.250,00 |
| Lucro identificado | R$ 682,24 |
| Dia com maior venda | Terça-feira |
| Venda registrada na terça-feira | R$ 1.000,00 |
| Região com maior faturamento | North |
| Faturamento da região North | R$ 1.350,00 |
| Dias com menores vendas | Quarta-feira e domingo |

> Os resultados representam uma análise demonstrativa realizada com uma base de dez registros e devem ser interpretados considerando o tamanho reduzido da amostra.
